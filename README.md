# 🛍️ NexusShop - Interactive E-commerce Product Catalog

[![Live Demo](https://img.shields.io/badge/Live_Demo-E_Commerce_Store-F97316?style=for-the-badge&logo=github)](https://af023.github.io/Tech-ecommerce-store/)

## 📌 Overview
NexusShop is a modern, responsive **E-commerce Product Catalog and Shopping Cart Application** built with HTML5, Tailwind CSS, and vanilla JavaScript. 

It features real-time category filtering, instant text search, a slide-out shopping cart drawer with dynamic quantity controls, total calculations, high-resolution product imagery, and a seamless bilingual (PT/EN) internationalization engine.

---

## ✨ Key Features
- **High-Resolution Product Imagery:** Integrated visual grid featuring professional tech gear images from Unsplash with hover zoom effects.
- **Dynamic Product Filtering & Search:** Instant category switching (Audio, Wearables, Accessories) and real-time name search responsiveness.
- **Interactive Slide-Out Cart Drawer:** Add items, adjust quantities, calculate live subtotals, view item thumbnails, and simulate checkouts.
- **Modern Retail Aesthetic:** Built with a sophisticated dark slate theme accented with vibrant amber-orange retail highlights.
- **Bilingual Internationalization (i18n):** Real-time language toggle supporting English and Portuguese interface components.

---

## 🛠️ Tech Stack
- **Markup:** HTML5 (Semantic).
- **Styling:** Tailwind CSS (Modern responsive layouts, glassmorphism panels).
- **State & Logic:** Vanilla JavaScript (ES6+, DOM manipulation, dynamic array filtering).
- **Icons:** Lucide Icons.
